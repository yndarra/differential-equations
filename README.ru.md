Явный и неявный методы Эйлера, написанные с нуля и сравнённые с адаптивным
методом Дорманда–Принса из SciPy на двух задачах:

1. **жёсткое** линейное уравнение, на котором явный метод ломается;
2. **полёт снаряда** с сопротивлением воздуха, зависящим от числа Маха, и
   кратковременной реактивной тягой.

![Явный и неявный Эйлер на жёстком уравнении](images/stiff_euler.png)

> Лабораторная работа по дисциплине «Компьютерное моделирование».

## Задача 1. Жёсткое уравнение

```
ε·s' + s = 0,   s(0) = 1,   t ∈ [0, 1],   ε ≪ 1
```

Точное решение — `s(t) = exp(−t/ε)`. Оно затухает почти до нуля за время
порядка `ε`, и дальше ничего интересного не происходит.

![Точные решения](images/stiff_exact.png)

На этом уравнении каждый шаг явного метода Эйлера умножает решение на
`1 − Δt/ε`, поэтому метод устойчив только при `Δt ≤ 2ε`. При `ε = 0.01` шаг
`Δt = 0.02` лежит ровно на границе устойчивости, множитель равен −1.
Численное решение не затухает и бесконечно скачет между +1 и −1 (левый график
выше). Неявный метод умножает на `1/(1 + Δt/ε)` — это меньше 1 при любом
шаге, поэтому он устойчив, каким бы большим ни был шаг.

![Сходимость и устойчивость](images/stiff_convergence.png)

* При `Δt ≪ ε` оба метода сходятся с **первым порядком**. Измеренный наклон —
  **1.01** у явного и **0.99** у неявного метода Эйлера.
* После `Δt = 2ε` ошибка явного метода взрывается, а у неявного остаётся
  ограниченной.

## Задача 2. Снаряд с сопротивлением и тягой

Вектор состояния — `Y = (x, y, Vx, Vy)`. На снаряд действуют силы:

* тяжести `mg`;
* сопротивления `½·ρ·V²·S·Cx(M)` против скорости. `Cx` зависит от числа
  Маха: 0.45 на дозвуке, трансзвуковой пик 0.95, затем 0.25 на больших
  сверхзвуковых скоростях;
* тяга `P(t)` вдоль скорости: 500 Н в течение первых 0.5 с.

Снаряд массой 30 кг и калибром 0.1 м запускается со скоростью 100 м/с под
углом 30°. Эталонное решение — `scipy.integrate.solve_ivp` с методом RK45
(Дорманд–Принс 5(4), тот же метод, что `dopri5`). Интегрирование
останавливается точно в момент падения: он находится через функцию-событие, а
не по первой точке с отрицательной высотой.

![Траектории](images/trajectories.png)

| Случай | Дальность | Время полёта | Высота |
|---|---|---|---|
| Вакуум, без тяги | 882.8 м | 10.19 с | 127.4 м |
| Сопротивление, без тяги | 844.6 м | 10.08 с | 124.5 м |
| Сопротивление + тяга | **979.2 м** | 10.85 с | 143.8 м |

Случай в вакууме совпадает с аналитической дальностью
`V₀²·sin 2θ / g = 882.8 м`. Серый пунктир — явный Эйлер всего с 20 шагами.
Его первый шаг длиннее всей работы двигателя, поэтому тяга действует слишком
долго, и траектория уходит выше истинной.

![Профиль тяги, координаты и скорость](images/kinematics.png)

Снаряд остаётся дозвуковым (максимальное число Маха — 0.31), поэтому `Cx`
постоянен на всём полёте.

![Ошибка дальности явного Эйлера](images/ballistic_convergence.png)

Ошибка дальности явного метода Эйлера относительно RK45 тоже убывает с
первым порядком. Измеренный наклон — **1.04**.

## Запуск

```bash
git clone https://github.com/yndarra/differential-equations.git
cd differential-equations
python -m venv .venv
.venv/Scripts/activate        # Windows; в Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt

python main.py                # обе задачи (около 10 с), картинки — в images/
python main.py stiff          # одна задача: stiff | ballistic
```

Тесты:

```bash
pip install -r requirements-dev.txt
pytest
```

## Структура проекта

```
ode_methods/
├── solvers.py    # явный Эйлер, неявный Эйлер (Ньютон), порядок сходимости
└── problems.py   # жёсткое уравнение, Cx(M), модель снаряда, событие падения
tests/            # сходимость, устойчивость, аналитические проверки
main.py           # решает обе задачи и рисует графики
```
